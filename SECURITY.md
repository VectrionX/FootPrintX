# Security and responsible use

## Product boundary

FootprintX is a client-side OSINT query-preparation interface. It does not scan systems, execute searches automatically, collect external content, perform identity verification, or operate as EASM/live monitoring.

## External navigation

Search provider navigation is intentionally two-step. The UI names the provider and displays the exact query before opening a new tab with `noopener noreferrer`. Provider data practices are outside this project’s control.

## Responsible use

Use only with documented authority and a defined scope. Do not use the application to access non-public data, evade provider controls, harvest credentials, or investigate people or systems without authorization. Query outputs are starting points for lawful, human-reviewed research—not findings or evidence.

## Reporting a vulnerability

Please report vulnerabilities privately to the project maintainer through the repository's security reporting channel. Include reproduction steps, affected versions, and impact. Do not include third-party personal data, credentials, or sensitive query results.
